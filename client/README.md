# Money Mitra — client

The React + TypeScript website for Money Mitra. See the [main README](../README.md) for what the
app does, how to run it locally, and how it's deployed.

```bash
npm run dev      # website on http://127.0.0.1:5173 (expects the API on http://localhost:5000)
npm test         # client tests
npm run lint     # lint
npm run build    # production build
```
